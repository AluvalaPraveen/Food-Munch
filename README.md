# 🍽️ Food Munch

A responsive food-ordering landing page built with **HTML** and **CSS**. It works on mobile, tablet and desktop screens.

## ✨ Features

- Responsive layout that adapts to mobile, tablet and desktop
- Navigation bar with smooth links to each section of the page
- Full-screen banner with **View Menu** and **Order Now** buttons
- **Why Choose Us?** cards: Food Service, Fresh Food and Best Offers
- **Explore Menu** grid with 8 food categories (Starters, Soups, Seafood, Main Course, Noodles, Salads, Desserts and more)
- Promotional section for fresh, organic fruits and veggies
- **Delivery and Payment** section with accepted payment icons (Visa, MasterCard, PayPal, American Express)
- **Follow Us** section with social media icons
- Footer with contact details

## 🛠️ Built With

| Technology | Used For |
|------------|----------|
| HTML5 | Page structure and semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`) |
| CSS3 | Styling, Flexbox layout and media queries |

## 🚀 Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/AluvalaPraveen/Food-Munch.git
```
2. **Open the folder**
```bash
   cd Food-Munch
```
3. **Open `index.html`** in any web browser (double-click the file).

No installation or build step is needed.

## 📱 Responsiveness

The layout is mobile-first. At screens **768px and wider**, the navigation moves to the right and the two-column sections switch from stacked to side by side.

## 📝 Notes

- Images are loaded from an external CDN, so an internet connection is needed to see them.
